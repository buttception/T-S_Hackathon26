Instructor only: the trainee never sees the behaviour labels.

1Scenario name

Before: the full name sat at the end of the control row in small grey text, and wrapped. After: a short name with domain and mode on its own line at the top of the panel, and the force list moved into colour chips.

2Mission brief

Before: one grey paragraph. After: Objective / Situation / Constraints, in normal text colour. The objective is also pinned on the map, so it stays visible on every tab.

3Behaviour labels hidden from the trainee

The map key no longer shows "Hostile state", "Grey-zone" and so on. They appear only in the instructor view, in the AI violet, so they read as AI behaviour settings.

4Two keys, clearly labelled

"Symbol = identity" and "Tag and zone = force" sit side by side, so red diamonds (hostile) aren't confused with the Red force itself.

5Collapsible key, one force row

The map key can be collapsed so it stops covering the map. The same force row is used in the legend, the Trainee tab, Setup and Instructor; only the instructor version adds unit count and behaviour.

!Colour to check

The pirate orange (#ff9f1c) is close to the status caution orange (#ffa94d) used for malfunction tags. Suggest moving pirates further from it, or leaving the caution colour only on panel chrome.
